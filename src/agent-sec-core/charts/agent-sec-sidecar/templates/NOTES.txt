agent-sec-cli, agent-sec-daemon, and Ollama are deployed in the same Pod.

Wait for the Pod:
  kubectl rollout status deployment/{{ include "agent-sec-sidecar.fullname" . }} \
    --namespace {{ .Release.Namespace }}

Run a fast prompt scan from the caller container:
  kubectl exec --namespace {{ .Release.Namespace }} \
    deployment/{{ include "agent-sec-sidecar.fullname" . }} \
    --container agent-sec-cli -- \
    agent-sec-cli scan-prompt --mode fast --text "hello"
